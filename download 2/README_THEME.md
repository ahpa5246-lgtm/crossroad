# مفترق الطرق — ملاحظات التحديث

- الشعار والاسم: لوحة الأدمن → الإعدادات (شعار فاتح + شعار داكن) و المحتوى → الرئيسية (اسم الموقع).
  الشعار ينعكس تلقائيا: النافبار، الفوتر، شاشة البداية، صفحات الدخول، أيقونة التطبيق/favicon، والشهادة.
- الأقسام (رسالتنا، هدفنا ...): لوحة الأدمن → المحتوى → الأقسام. عنوان + كتابة حرة، بأي عدد وترتيب.
- الشهادة: لوحة الأدمن → المحتوى → الشهادة (اسم وصفة الموقّع).
- أول فتح للموقع يشغّل ترحيل تلقائي: يغيّر الاسم، يحوّل نصوص (عن/أهداف) القديمة لأقسام حرة، ويفرّغ الشعار القديم.
- ما تم تضمين .env ولا قاعدة البيانات داخل ملف التحديث حتى ما تنمسح بياناتك.
